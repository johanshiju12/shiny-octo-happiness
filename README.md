# NCEA Hub WinUI App

This repository contains a starter WinUI 3 (C++/WinRT) Windows application for **NCEA Hub**.

## Getting Started

1. Open `NceaHubApp.sln` in Visual Studio 2022 with the **Desktop development with C++** and **Windows App SDK** workloads installed.
2. Build and run the `NceaHubApp` project.

## Project Structure

- `src/NceaHubApp` - WinUI 3 C++/WinRT project source.

## Notes

This is a minimal scaffold meant to be extended with NCEA Hub features (dashboard, course data, notifications, etc.).
